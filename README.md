# 🤍✦ Memo Todo

윈도우 스티커 메모 스타일의 **투두리스트 + 메모 결합 데스크톱 앱**입니다.
Electron 기반이라 Windows / macOS / Linux 어디서나 동작합니다.

기록하는 게 편한 사람을 위해, 지저분하지 않고 파스텔 감성으로 정리되도록 만들었어요.

## ✨ 기능

### 할 일 (투두)
- 우측 상단 **＋ 버튼**을 누르면 파스텔 **네모 블럭**이 생깁니다.
- 블럭은 `[할 일 제목] + [체크리스트 세부항목]` 구조입니다.
- 세부항목을 **체크하면** 취소선 + 회색으로 처리되고 **자동으로 맨 아래로** 내려갑니다.
- 항목이 많아지면 블럭 길이가 **자동으로 늘어납니다.**
- 세부항목 입력 중 `Enter`로 다음 항목 추가, 빈 항목에서 `Backspace`로 삭제.
- 상단 검색창으로 블럭 제목·항목을 필터링할 수 있습니다.

### 메모
- 상단 **메모 탭**으로 전환하거나, 타이틀바의 **🗔 버튼**으로 별도 창으로 띄울 수 있습니다.
- 본문은 **하나의 페이지**이며, **구분선**을 기준으로 각각을 하나의 메모로 취급합니다.
- 구분선 바로 아래 **첫 문장이 그 메모의 제목**이 됩니다.
- 왼쪽 **목차(인덱스)** 에 메모 제목들이 다이어리처럼 나열됩니다. 클릭하면 해당 위치로 이동합니다.
- **폴더**를 만들고, 목차의 메모를 **드래그**해서 폴더에 정리할 수 있습니다.
- **Ctrl+F** 로 메모 안에서 내용을 직접 검색할 수 있습니다. (`Enter`/`Shift+Enter`로 다음·이전 이동)

### 공통
- 프레임 없는 커스텀 창, **📌 항상 위 고정**, 최소화/닫기 버튼.
- 데이터는 사용자 폴더(`userData/memo-todo-data.json`)에 자동 저장됩니다.
- 여러 창을 띄워도 변경 사항이 서로 동기화됩니다.

## 🚀 실행 (비전공자용, 윈도우 기준)

처음 한 번만 설정하면 됩니다.

1. **Node.js 설치** — https://nodejs.org 에서 **LTS** 버튼으로 받아 다음다음 설치.
2. **코드 받기** — GitHub 저장소에서 초록색 **Code → Download ZIP** → 압축 풀기.
3. **그 폴더에서 명령창 열기** — 폴더 주소창에 `cmd` 입력 후 Enter.
4. **명령 입력** (한 줄씩 Enter):

```bash
npm install     # 부품 다운로드 (처음 한 번, 몇 분 걸림)
npm start       # 앱 실행
```

> 맥/리눅스도 동일합니다. 2번부터 따라하면 돼요.
> 나중에 더블클릭 실행되는 설치 파일이 필요하면 `npm run dist` 로 만들 수 있어요.

## ☁ 여러 기기 동기화 (선택)

다른 컴퓨터에서도 같은 할 일/메모를 보고 싶다면 **[SYNC-SETUP.md](SYNC-SETUP.md)** 를
따라 Supabase(무료)를 한 번 연결하세요. 설정 안 하면 그냥 내 컴퓨터에만 저장됩니다.

```bash
npm run dist    # 현재 OS용 설치 파일 생성 (electron-builder)
```

```

preload.js           안전한 IPC 브리지 (contextBridge)
renderer/
  index.html         레이아웃
  styles.css         파스텔 핑크 테마
  app.js             투두/메모/검색 렌더러 로직
```
