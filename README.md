# 🤍✦ Memo Todo

윈도우 스티커 메모 스타일의 **투두리스트 + 메모 결합 데스크톱 앱**입니다.
Electron 기반이라 Windows / macOS / Linux 어디서나 동작합니다.

기록하는 게 편한 사람을 위해, 지저분하지 않고 파스텔 감성으로 정리되도록 만들었어요.

## ✨ 기능

### 할 일 (투두)
- 우측 상단 **＋ 버튼**을 누르면 파스텔 **네모 블럭**이 생깁니다.
- 블럭은 `[할 일 제목] + [체크리스트 세부항목]` 구조입니다.
- 세부항목을 **체크하면** 취소선 + 회색으로 처리되고 **자동으로 맨 아래로** 내려갑니다.
- 항목이 많아지면 블럭 길이가 **자동으로 늘어납니다.**
- 세부항목 입력 중 `Enter`로 다음 항목 추가, 빈 항목에서 `Backspace`로 삭제.
- 상단 검색창으로 블럭 제목·항목을 필터링할 수 있습니다.

### 메모
- 상단 **메모 탭**으로 전환하거나, 타이틀바의 **🗔 버튼**으로 별도 창으로 띄울 수 있습니다.
- 본문은 **하나의 페이지**이며, **구분선**을 기준으로 각각을 하나의 메모로 취급합니다.
- 구분선 바로 아래 **첫 문장이 그 메모의 제목**이 됩니다.
- 왼쪽 **목차(인덱스)** 에 메모 제목들이 다이어리처럼 나열됩니다. 클릭하면 해당 위치로 이동합니다.
- **폴더**를 만들고, 목차의 메모를 **드래그**해서 폴더에 정리할 수 있습니다.
- **Ctrl+F** 로 메모 안에서 내용을 직접 검색할 수 있습니다. (`Enter`/`Shift+Enter`로 다음·이전 이동)

### 프로젝트 (마감 관리)
- **프로젝트 탭**에서 ＋ 버튼으로 마감이 있는 프로젝트 카드를 만듭니다.
- 각 카드에 **마감일(D-데이 배지)** 과 **진행도 바**(칸을 눌러 진행률 조절, 칸 수 변경 가능)를 둡니다.
- 마감이 가까운 순으로 자동 정렬되고, 진행 100%가 되면 **완료 처리**되어 맨 아래로 내려갑니다.

### 월간 일정
- **일정 탭**의 월간 달력에서 날짜를 눌러 그 날의 일정을 추가·수정합니다(제목·시간·색).
- 달력 셀에는 **일정/마감 점 표시**가 뜨고, 프로젝트 마감과 D-DAY도 함께 보입니다.

### thinking cycle (주기 예측)
- **사이클 탭**에서 반복되는 일(예: 아이디어 정리, 대청소)을 만들고 **발생 날짜를 기록**합니다.
- 기록이 2개 이상 쌓이면 **평균 주기·범위·다음 예상일(D-데이)** 을 자동으로 계산해 보여줍니다.

### 임박 마감 알림
- 프로젝트 마감·일정·D-DAY 중 **D-3 이내**(및 지난 마감)를 상단 **알림 배너**로 모아 보여줍니다.
- 오늘이 마감(D-DAY)인 항목은 하루 한 번 **OS 알림**으로도 알려줍니다.

### 공통
- 프레임 없는 커스텀 창, **📌 항상 위 고정**, 최소화/닫기 버튼.
- 데이터는 사용자 폴더(`userData/memo-todo-data.json`)에 자동 저장됩니다.
- 여러 창을 띄워도 변경 사항이 서로 동기화됩니다.
- **부팅 시 자동 실행** — 설치본에서는 컴퓨터를 켜면 앱이 자동으로 뜹니다(스티커 메모처럼).
  끄고 싶으면 데이터 설정의 `autoLaunch`를 `false`로 두면 됩니다.
- **창 위치·크기 기억** — 창을 옮기거나 크기를 바꾸면 그 자리를 기억했다가 다음에 그대로 띄웁니다.
- **단일 실행** — 이미 떠 있으면 새 창이 중복으로 뜨지 않고 기존 창을 앞으로 가져옵니다.

## 🚀 실행 (비전공자용, 윈도우 기준)

처음 한 번만 설정하면 됩니다.

1. **Node.js 설치** — https://nodejs.org 에서 **LTS** 버튼으로 받아 다음다음 설치.
2. **코드 받기** — GitHub 저장소에서 초록색 **Code → Download ZIP** → 압축 풀기.
3. **그 폴더에서 명령창 열기** — 폴더 주소창에 `cmd` 입력 후 Enter.
4. **명령 입력** (한 줄씩 Enter):

```bash
npm install     # 부품 다운로드 (처음 한 번, 몇 분 걸림)
npm start       # 앱 실행
```

> 맥/리눅스도 동일합니다. 2번부터 따라하면 돼요.
> 나중에 더블클릭 실행되는 설치 파일이 필요하면 `npm run dist` 로 만들 수 있어요.

## 🖥 배경화면 위젯 모드 (Windows)

노션 개인 홈처럼 **배경화면에 박아두고 쓰는 위젯 모드**입니다. `⚙ 설정 → 배경화면 위젯`
에서 켜거나, 오른쪽 아래 **트레이 아이콘**을 우클릭해 토글할 수 있습니다.

- **작업표시줄·Alt-Tab 목록에서 빠집니다.** 다른 창들과 섞여 정신없어지지 않아요.
- **창을 닫아도(✕) 종료되지 않고 트레이로 숨습니다.** 창 정리하다 실수로 없애버리는 걸 막아줍니다.
  다시 열려면 트레이 아이콘을 클릭, 완전히 끄려면 트레이 우클릭 → **종료**.
- **항상 위 고정** 옵션을 켜두면 위젯이 다른 창 뒤로 사라져 "실종"되는 사고를 방지합니다.
  (끄면 일반 창처럼 뒤로 갈 수 있습니다.)

> 참고: Windows에서 진짜 "벽지 레이어에 파묻는"(바탕화면 아이콘 아래로 완전히 박는) 동작은
> OS 네이티브 훅이 필요해 이 앱은 지원하지 않습니다. 대신 위처럼 **작업표시줄에서 빠지고 +
> 항상 위 + 실수 방지(트레이 상주)** 로 배경 위젯처럼 상시 띄워두는 방식입니다.

## 💾 자동 백업 (매일 로컬 스냅샷)

`⚙ 설정 → 백업`에서 켜면 **매일 자동으로 데이터 스냅샷**을 저장합니다.
**최신 1개만 남기고 이전 백업은 자동 삭제**됩니다(요청하신 "최근 거 올리면서 이전 건 지워지게").

- 별도 로그인·키 설정이 필요 없습니다. 앱을 켜면 그 날 첫 실행 때 백업이 만들어집니다.
- **구글드라이브에 매일 올리고 싶다면:** 백업 폴더를 **구글드라이브 데스크톱 동기화 폴더**
  (예: `내 드라이브\...`)로 지정하세요. 그러면 구글드라이브 앱이 알아서 매일 업로드하고,
  파일은 최신 1개만 유지되니 드라이브에서도 이전 파일이 새 파일로 대체됩니다.
  (구글 OAuth 키 발급 같은 복잡한 설정 없이 같은 목적을 달성합니다.)
- 백업 파일: `memo-todo-backup-YYYY-MM-DD.json`. `설정 → 지금 백업`으로 즉시 백업도 가능합니다.

## ☁ 여러 기기 동기화 (선택)

다른 컴퓨터에서도 같은 할 일/메모를 보고 싶다면 **[SYNC-SETUP.md](SYNC-SETUP.md)** 를
따라 Supabase(무료)를 한 번 연결하세요. 설정 안 하면 그냥 내 컴퓨터에만 저장됩니다.

## 📱 아이폰/안드로이드에서 보기·편집 (모바일 웹앱)

동기화를 켰다면 `docs/` 폴더의 **모바일 웹앱**으로 폰에서도 확인·수정할 수 있습니다.

1. GitHub 저장소 → **Settings → Pages** → Source: *Deploy from a branch* →
   브랜치와 폴더(`/docs`) 선택 → Save. (무료 플랜은 저장소가 **공개(public)** 여야 합니다 —
   개인 키는 저장소에 없으니 공개해도 안전)
2. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 주소가 생깁니다.
3. 아이폰 Safari로 접속 → 최초 1회 **supabaseUrl / anonKey**(PC의 config.json과 같은 값)
   입력 → 동기화 계정으로 로그인.
4. 공유 버튼(□↑) → **홈 화면에 추가** → 앱 아이콘처럼 사용.

기능: 투두 체크/수정/추가, 메모 열람·편집·추가, 체크리스트 탭 토글, 실시간 반영.
PC 앱과 같은 계정·같은 데이터(마지막 저장 우선)로 동작합니다.

## 📦 빌드(설치 파일 .exe)

윈도우 설치 파일(`.exe`)을 만들려면 **윈도우 PC에서** 아래를 실행하세요.

```bash
npm install       # 부품 다운로드 (처음 한 번)
npm run dist:win  # Windows 설치 파일 생성 (electron-builder, NSIS)
```

- 완료되면 `dist\Memo Todo Setup 0.1.0.exe` 가 생성됩니다. 그 파일을 더블클릭해 설치하면 됩니다.
- 설치 시 **설치 경로 선택 + 바탕화면/시작메뉴 바로가기**가 만들어지고, 설치 후 실행하면
  **부팅 시 자동 실행**이 켜집니다(위 "공통" 참고). 앱/설치 아이콘은 `build/icon.ico`(노트 아이콘)입니다.
- `npm run dist` 는 실행 중인 OS용(맥=dmg, 리눅스=AppImage) 설치본을 만듭니다.

> **`Cannot create symbolic link` 오류가 나면** (winCodeSign 압축 해제 권한 문제):
> 관리자 권한 대신 **윈도우 개발자 모드**를 한 번만 켜면 됩니다 —
> 설정 → 개인 정보 및 보안 → **개발자용 → 개발자 모드 ON**. 그 뒤 일반 cmd에서 `npm run dist:win`.
> (개발자 모드는 관리자 권한이 아니라 심볼릭 링크 생성만 허용하는 일회성 토글입니다.)

> 참고: 이 저장소를 클라우드/리눅스 CI에서 빌드하면 Electron 바이너리 다운로드가
> 사내 정책으로 막혀 실패할 수 있습니다. 윈도우 실물 PC에서 빌드하는 것을 권장합니다.

## 🗂 구조

```
main.js              Electron 메인 프로세스 (창 생성/위치기억/자동실행, 위젯·트레이·백업, 데이터 IPC)
preload.js           안전한 IPC 브리지 (contextBridge)
sync.js              Supabase 동기화(선택)
renderer/
  index.html         메인 창 레이아웃
  editor.html        메모 상세편집 창
  styles.css         파스텔 핑크 테마
  shared.js          두 창 공용 로직(서식 툴바/이미지/색상 등)
  app.js             투두/메모/검색 + 뷰(탭) 시스템 렌더러
  features.js        프로젝트/월간일정/사이클/설정·백업/임박알림 로직
  editor.js          상세편집 창 로직
```

## 📝 데이터 모델

```jsonc
{
  "ddays":    [ { "id", "title", "date" } ],
  "todos":    [ { "id", "title", "color", "items": [ { "id", "text", "done" } ] } ],
  "folders":  [ { "id", "name", "collapsed" } ],
  "memos":    [ { "id", "folderId", "content" } ],
  "projects": [ { "id", "title", "color", "deadline", "segs", "progress", "done", "note" } ],
  "events":   [ { "id", "title", "date", "time", "color", "note" } ],
  "cycles":   [ { "id", "name", "color", "entries": [ "YYYY-MM-DD" ], "note" } ]
}
```

> 위젯/백업 설정은 기기별 로컬 파일(`userData/widget-config.json`)에 따로 저장되어
> 동기화되지 않습니다(폴더 경로 같은 기기 고유 값이라 기기마다 달라야 하므로).
